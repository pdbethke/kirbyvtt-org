kirby-cost is the build and cost engine behind Kirby: a Python port of Hero
Designer's own cost calculations. It reads a HERO 6E build and costs it the
way Hero Designer does.

It is validated against Hero Designer, not merely modeled on it: 656 of 656
characters match, on every object and on every character total.

## Install

```sh
pip install kirby-cost
```

kirby-cost requires a Hero Designer installation and your own rulebooks. It
ships no templates, no rules text, and no Hero Games content.
