kirby-combat is a pure-Python HERO 6E combat engine, with zero runtime
dependencies. It is covered by 905 tests spanning attacks, grappling,
movement, mental combat, vehicles, mass combat, destructible terrain, and
Presence attacks.

## Install

```sh
pip install kirby-combat
```

kirby-combat needs no Hero Designer installation and no character file —
combatants are plain Python objects. It ships no rules text and no Hero
Games content; the numbers still come from your own rulebooks.
